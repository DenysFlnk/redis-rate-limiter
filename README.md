# Rate Limiter Implementation

This repository contains the implementation of a Rate Limiter system using three approaches:

1. **Fixed Window Rate Limiter**
2. **Sliding Window Rate Limiter**
3. **Sliding Window Rate Limiter using Lua**

## Branches
- **`develop`**: Contains the template code with TODOs for implementation.
- **`completed`**: Contains the fully implemented solution.

## Task Description
The goal of this project is to create a rate-limiting mechanism that controls the number of requests a user can make within a specified time window. The rate limiter will:
- Restrict users based on their request rate.
- Use Redis for state storage to ensure distributed scalability.

## Implementation Order
1. **Fixed Window Rate Limiter**
2. **Sliding Window Rate Limiter**
3. **Sliding Window Rate Limiter with Lua Script**
